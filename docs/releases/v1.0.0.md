# EvoRacer AI Lab v1.0.0

The first stable portfolio release packages the complete offline Windows x64
application proven through Phases 0-10.

## Included

- Preset, modular, generated, imported, and locally saved tracks through one
  Python-owned deterministic compiler.
- Fixed-step arcade physics, seven road-edge sensors, Fixed GA, and feed-forward
  NEAT through the shared Python evaluator.
- Explicit Start, generation-batched observation, pause/resume/stop, telemetry,
  results, baseline comparison, replay, and deterministic run recovery.
- A self-contained `EvoRacer.exe` bundle with local frontend assets, runtime
  dependencies, user guide, notices, and licenses.

## Install

1. Download `EvoRacer-Windows-x64.zip` and
   `EvoRacer-Windows-x64.zip.sha256`.
2. Verify the ZIP with the published SHA-256 value.
3. Extract the complete archive.
4. Open `EvoRacer\EvoRacer.exe`.

Node.js and Python are not required on the target computer. The application
stores user data under `%LOCALAPPDATA%\EvoRacerAILab`.

## Evidence boundary

The release was accepted with outbound networking disabled and exposed only its
loopback service. Saved deterministic regression and controlled training
fixtures support the repository's reproducibility and learning statements.
They are not a claim that every seed, track, or training configuration improves,
nor that Fixed GA or NEAT is universally superior.

Full methods and limitations remain in
[`docs/verification/phase10-hardening.md`](../verification/phase10-hardening.md)
and [`docs/algorithm-comparison.md`](../algorithm-comparison.md).
