# EvoRacer AI Lab v1.1.0

This personal offline release focuses on clearer experimentation, durable
evolution history, and a transparent portable Windows package.

## Included

- Redesigned Track Builder with focused Build, Generate, and Library tabs,
  Python validation, explicit track selection, and safer editing controls.
- Smooth live candidate observation and generation-champion replay with a
  bounded Evolution trail restored from the local run checkpoint.
- Previous-run comparison restricted to identical track and evaluation budgets.
- Correct generation-boundary Pause and Stop behavior even when requested
  immediately after Start.
- A transparent portable folder: `EvoRacer.cmd`, plain application modules and
  web assets under `app`, and an isolated bundled Python runtime under `runtime`.
  There is no frozen `EvoRacer.exe`.

## Install

1. Download `EvoRacer-Windows-x64.zip` and its matching checksum file.
2. Verify the SHA-256 value and extract the complete archive.
3. Open `EvoRacer\EvoRacer.cmd`.

Node.js and a system Python installation are not required. Runtime traffic stays
on `127.0.0.1`, and user data stays under `%LOCALAPPDATA%\EvoRacerAILab`.

## Evidence boundary

The release gate covers deterministic Fixed GA/NEAT smoke cases, the portable
offline package lifecycle, a real Chromium user flow, and one complete Thorough
NEAT preset. These are reproducibility and reliability checks, not a universal
claim that every evolutionary run improves.
